# TriClima SC

App de previsão do tempo para triatlo em Santa Catarina: treinos programados com horário sugerido, alternativa indoor, hidratação e alimentação, previsão hora a hora (chuva, vento, temperatura, mar) e performance do Strava.

Abra em https://viniciusbrock92-hash.github.io/triclima/ e, no Chrome do Android, toque em ⋮ → Adicionar à tela inicial.

Dados de previsão: [Open-Meteo](https://open-meteo.com/).
